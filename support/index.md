# 念流 NianFlow 支援

使用上有任何問題或建議，請來信：<wdhsieh99@gmail.com>，通常會在 2 個工作天內回覆。來信時附上手機機型、系統版本（iOS 或 Android）與截圖，可以更快找到問題。

## 常見問題

### 需要付費嗎？

念流免費下載使用。AI 功能（整理轉錄文字、匯流、重整念流、寫成文章、解讀照片）需要你自備 OpenAI 或 DeepSeek 的 API Key，費用由服務商依用量向你收取；在「設定 › AI 用量」可以查看每月的用量與估算費用。

### 怎麼取得 API Key？

到「設定 › AI 服務」選擇 OpenAI 或 DeepSeek，點「取得 API Key」前往服務商網站申請，複製後貼回念流，按「驗證並儲存」。第一次使用前會顯示資料傳送同意畫面，同意後才會傳送。

### 沒有 API Key 可以用嗎？

可以。錄音、轉文字、拍照、整理念頭、播報都不需要 Key；在「寫成文章」選「複製並開啟」AI 助理，把念流帶到你慣用的 AI 網站（可在設定選擇），討論完再貼回念流存成文章。

### 我的錄音會傳出手機嗎？

不會。錄音只在手機上用 Apple 的語音辨識轉成文字。傳送給 AI 服務的只有文字（使用 OpenAI 解讀照片時另含照片）。詳見[隱私權政策](../privacy/)。

### 怎麼不打開 App 就錄音？

- **鎖定畫面**：長按鎖定畫面 › 自訂 › 鎖定畫面 › 加入小工具 › 念流「錄下念頭」。
- **Siri**：說「用念流記下念頭」。
- **動作按鈕**（支援的 iPhone 機型）：設定 › 動作按鈕 › 捷徑 › 念流 › 錄音記下念頭。
- **Apple Watch**：打開手錶上的念流按一下就錄。
- **背面輕點**：把念流的捷徑指定給「背面輕點」，輕點手機背面就錄（設定方式見下一題）。

不用解鎖，錄音時鎖定畫面與動態島會顯示錄音中，按「完成」或再觸發一次就結束。

### 看電子書時怎麼記下想法？

不用離開閱讀 App，有四種方式。念流「設定 › 閱讀時快速記錄」裡也有同樣的步驟。

**截圖＋錄音一次完成**（最推薦）

1. 打開「捷徑」App 新增一個捷徑，先加入系統的截圖動作（搜尋「截圖」或「螢幕快照」）。
2. 接著加入念流的「截圖記下念頭」，它會自動拿到上一步的截圖。
3. 到 iPhone「設定 › 輔助使用 › 觸控 › 背面輕點」，選「點三下」指定這個捷徑（有動作按鈕的 iPhone 也可以指定給動作按鈕）。
4. 看到想記的段落就輕點手機背面三下：截下這一頁並開始錄音，說完再點一次，或按鎖定畫面與動態島的「完成」。

截圖和你說的話會存成同一個念頭；轉成文字後，念流會一起解讀這張截圖。

**只錄音**：新增一個只有念流「錄音記下念頭」的捷徑，在「背面輕點」選「點兩下」指定它，輕點兩下就開始錄。

**從分享選單傳入截圖**

1. 按按鍵截圖後，點左下角的縮圖，再點「分享」。
2. 選「念流」（第一次要在分享列最右邊的「更多」裡打開）。
3. 可以打一句說明，按「存入」回到原本的 App。截圖會在下次打開念流時出現在念頭匣。

iOS 的分享選單不能使用麥克風，所以這裡只能打字；想邊看邊說，請用上面的「截圖＋錄音」。

**在念流裡匯入最新截圖**：長按捕捉頁的「拍照」，選「最新截圖」，念流會拿相簿裡最新的一張截圖並直接開始錄語音說明。照片權限要選「完整取用」，念流只會讀取最新的那一張截圖。

### 截圖會傳出手機嗎？

截圖和拍照的念頭處理方式相同：設定了 OpenAI Key 時，會在你同意後把截圖送給 OpenAI 解讀內容；沒有 OpenAI Key 時，只在手機上用 Apple 的文字辨識擷取文字。

### Apple Watch 錄的念頭沒有出現在 iPhone？

手錶錄完會在 iPhone 附近時自動傳送，手錶畫面會顯示「等待傳到 iPhone」的數量。請確認手錶與 iPhone 已配對、藍牙與 Wi-Fi 開啟，並打開一次 iPhone 上的念流；傳到之後會自動轉成文字。

### 播報時怎麼插入新想法？

播報念流時點「插入念頭」，或按一下耳機的「下一首」（例如 AirPods 按兩下），說完就會記下並歸入這條念流，然後從剛才的句子接著播。

### iCloud 同步沒有作用？

請確認 iPhone 已登入 iCloud，且「設定 › Apple 帳號 › iCloud」裡念流的 iCloud 開啟。iCloud 儲存空間已滿時無法同步，念流「設定 › iCloud 同步」會顯示錯誤原因。

### 怎麼刪除我的資料？

在念流中刪除念頭、念流或文章，會一併從 iCloud 刪除。刪除 App 會移除手機上的資料；iCloud 中的資料可在「設定 › Apple 帳號 › iCloud › 管理帳號儲存空間」刪除。已傳送給 AI 服務的資料，請依該服務的政策申請刪除。

## Android 版

### 系統需求

Android 13 以上。Android 版有念流的核心流程：錄音、拍照、文字念頭，轉文字、匯流、播報與插入念頭、寫成文章與交給 AI 助理討論；沒有手錶、小工具、雲端同步與 AI 用量。

### 錄音沒有轉成文字？

Android 版用系統的裝置端語音辨識，第一次使用要下載中文語音模型：到念流「設定 › 語音轉文字」按「下載中文語音模型」，下載完成後在念頭詳情按「重試」。手機不支援裝置端辨識時會顯示原因；念流不會改用雲端辨識，錄音不會傳出手機。

### 播報沒有聲音或提示沒有中文語音？

念流只使用安裝在手機上的離線中文語音。請到系統「設定 › 無障礙 › 文字轉語音輸出」，在偏好的引擎（例如 Google 語音服務）中安裝「中文（台灣）」語音資料，再回到念流播報。

### 播報時怎麼插入新想法？

和 iPhone 一樣：點「插入念頭」，或按耳機的「下一首」，說完停頓幾秒會自動結束並接著播。螢幕關閉時也可以用耳機或通知列的「插入念頭」。插入的錄音目前使用手機的麥克風。

### 看書時怎麼記下想法？

- **分享截圖**：截圖後點「分享」選「念流」，畫面上會出現念流的小視窗並馬上開始錄語音說明（也可以改打一句），按「存入」就回到原本的 App。
- **快速設定方塊**：下拉通知列 › 編輯（鉛筆圖示）› 把念流的「錄下念頭」拖進快速設定。看書時下拉點一下就開始錄，說完停頓幾秒會自動存入並回到原本的 App。

錄音只在小視窗開著時進行；中途切走時，已經錄好的內容會先存下來。

### 資料存在哪裡？怎麼刪除？

Android 版的資料只存在這支手機，沒有雲端同步，也不會備份到 Google 雲端硬碟。在念流中刪除就會從手機刪除；刪除 App 會移除全部資料（換手機時資料不會帶過去）。
